# Out of My Way

**Keeps tamed animals out of the way.**

Available on [Modrinth](https://modrinth.com/mod/out-of-my-way/) and [CurseForge](https://www.curseforge.com/minecraft/mc-mods/out-of-my-way).

## 📖 Features

* Tamed animals (wolves, cats and parrots) are relocated behind you when they get too close or in your way.
* Configurable per-animal-type
* Optionally, relocate animals within your view.

## 📋 Usage

### Pausing / interacting

Hold the animal's taming item (e.g. a bone for wolves) to temporarily pause functionality, so you can interact with the animal. Normal behaviour will resume after a set delay (can be configured).

### Configuration

Open the config screen via **Mod Menu** or by running `/out-of-my-way config` in chat.
